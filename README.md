# A React typescript clothes Ecomerce App

### Features

- Built with **React** and **TypeScript** for robust and scalable UI development.
- Uses **Redux** and **Redux Toolkit** for state management, with support for **redux-thunk**, **redux-saga**, and **redux-logger** for advanced asynchronous flows and debugging.
- State persistence using **redux-persist**.
- Styled with **Sass** and **styled-components** for customizable and modular styles.
- Integrated with **Firebase** for backend services (authentication, data storage, etc.).
- Payment processing via **Stripe** integration (**@stripe/react-stripe-js**, **@stripe/stripe-js**, **stripe**).
- Routing with **react-router-dom** (v6).
- Selectors with **reselect** for efficient state selection.
- Testing setup includes **enzyme** and **@testing-library/react**.
- Enhanced developer experience with TypeScript definitions for many dependencies.
- Additional support and utilities from **dotenv** for environment management.

**Development and build tools:**

- Uses **react-scripts** for building and running the app.
- Linting and code quality via **eslint**.
- Includes **workbox** packages for advanced service worker/caching strategies.

\*See `package.json` for full list of dependencies and details.
